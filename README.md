# إيه يا عم؟ — EH YA AM · لعبة تحديات وأسئلة للرحلات

لعبة عربية باللهجة المصرية، مصممة لمضيف واحد يستخدم موبايلًا واحدًا لإدارة المنافسة بين فريقين. لا تحتاج حسابات أو Backend أو قاعدة بيانات أو أي خدمة مدفوعة.

## ما الموجود في النسخة الحالية؟

- 10 فئات × 20 سؤالًا/تحديًا = **200 سؤال وتحدٍ** محليًا داخل المشروع.
- أسئلة معلومات عامة، ألغاز وصف، أسئلة هبلة بذكاء، سرعة بديهة، ألغاز منطق، مواقف مضحكة، مصر والدنيا، ثقافة عامة، صح ولا غلط، وتحديات جرأة خفيفة.
- تلميحات وإجابات لا تظهر إلا بضغط المضيف، ومعايير تحكيم للتحديات الإبداعية.
- تسجيل نقطة لفريق واحد، تعادل بلا نقاط، تخطي، ومنع تكرار احتساب السؤال، مع التراجع عن آخر تسجيل.
- تغيير أسماء الفريقين وقيمة النقاط، وتفضيلات الصوت والحركة والمؤقت.
- حفظ النقاط والجلسة والإعدادات في LocalStorage، واسترجاعها عند إعادة فتح الصفحة في المتصفح نفسه.
- نتائج حسب الفئة، تصدير JSON وCSV، وصفحة طباعة للنتائج.
- تصميم RTL متجاوب، وصفحة تعريف بالمطوّر مع صورة كلب مرحة وروابط قابلة للإضافة من ملف إعدادات.
- manifest وService Worker لتثبيت اللعبة والعمل دون اتصال بعد تحميل مواردها وتخزينها بنجاح.

## تشغيل محلي سريع

**لا يوجد Build ولا تحتاج لتثبيت Dependencies.**

1. فك ضغط الملف.
2. افتح المجلد.
3. للاستخدام السريع على الكمبيوتر، افتح `index.html` في متصفح حديث. يظل اللعب الأساسي متاحًا، لكن خدمة PWA والعمل دون اتصال يحتاجان إلى تشغيل الموقع عبر HTTP/HTTPS.
4. لتجربة PWA والعمل دون اتصال، شغّل خادمًا محليًا من داخل المجلد:

   ```bash
   python -m http.server 8000
   ```

   ثم افتح `http://localhost:8000`.

## فتح اللعبة على موبايل

- للنشر عبر HTTPS: ارفع المجلد إلى Vercel ثم افتح رابط الموقع على الهاتف.
- أو وصّل الكمبيوتر والهاتف على شبكة Wi‑Fi واحدة، وشغّل الخادم المحلي، ثم افتح من الهاتف عنوان IP المحلي للكمبيوتر مع `:8000` بدل `localhost`.
- في Android عبر Chrome: افتح الموقع ثم قائمة المتصفح واختر **Install app** أو **Add to Home screen** (قد يختلف النص حسب الإصدار).
- في iPhone عبر Safari: افتح الموقع، اضغط Share ثم **Add to Home Screen**.
- أول زيارة تحتاج اتصالًا لتحميل الموارد؛ بعد اكتمال تخزينها قد تعمل الموارد الأساسية دون اتصال. لا تفتح `index.html` مباشرة إذا كنت تختبر PWA.

## النشر على Vercel مجانًا

### من واجهة Vercel

1. أنشئ مستودع Git جديدًا وارفع محتويات مجلد `battle-trip` إلى جذر المستودع.
2. في Vercel، اختر **Add New → Project** واستورد المستودع.
3. اترك Framework Preset على **Other**، واترك Build Command فارغًا، واجعل Output Directory هو `.` إن طلب منك.
4. اضغط Deploy. لا توجد متغيرات بيئة أو قاعدة بيانات مطلوبة.

### أو باستخدام Vercel CLI

إذا كانت الأداة مثبتة عندك:

```bash
vercel
vercel --prod
```

## إضافة روابط المطوّر

افتح `config.js` وعدّل قيم `url` الفارغة في `portfolioLinks` (GitHub وLinkedIn وInstagram وCV) وضع إيميلك في `contactEmail`. أي رابط فارغ بيظهر باهتًا وغير قابل للضغط، ولا توجد روابط مفبركة.

## التخزين والخصوصية

النقاط والأسماء وسجل الجلسة محفوظة في **LocalStorage الخاص بالمتصفح على الجهاز الحالي**. لا توجد مزامنة بين أجهزة أو مستخدمين، ومسح بيانات المتصفح قد يمسح الجلسة؛ استخدم تنزيل النتائج للاحتفاظ بنسخة.

## الملفات الرئيسية

- `index.html` — نقطة تشغيل التطبيق.
- `styles.css` — التصميم المتجاوب ونظام الألوان.
- `app.js` — التنقل، تسجيل النقاط، الإعدادات، الحفظ، النتائج والتصدير.
- `questions.js` — الفئات وبنك الأسئلة الأساسي.
- `questions-extra.js` — تحسين بعض الأسئلة وإضافة 100 سؤال وتحدٍ إضافي.
- `config.js` — اسم المطوّر ونبذته وروابطه وإيميل التواصل.
- `manifest.json` و`sw.js` — إعدادات PWA والكاش.
- `assets/` — الأيقونة وصورة صفحة المطوّر.
- `QA_REPORT.md` — ملخص الفحوصات التي تم تنفيذها.

## ملاحظة عن التحكيم

التحديات الإبداعية وسرعة البديهة يُحسم الفائز فيها بواسطة المضيف وفق معيار التحكيم المكتوب. الأسئلة المعرفية والمنطقية لها إجابات أو شروح مرفقة. راجعوا الأسئلة قبل الرحلة، خصوصًا إذا كانت مجموعتكم تعتمد قواعد خاصة لاحتساب الإجابة المقبولة.
